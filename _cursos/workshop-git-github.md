## Workshop Git/GitHub

Este workshop apresenta o Git como ferramenta de controle de versão e o GitHub
como ambiente de colaboração, documentação e publicação de projetos. Cada
conceito é aplicado imediatamente em um repositório criado pela própria turma.

### Objetivos

- compreender repositório, área de preparação, commit e histórico;
- criar e sincronizar repositórios locais e remotos;
- trabalhar com branches sem comprometer a linha principal;
- resolver conflitos de maneira consciente;
- colaborar por issues, pull requests e revisões;
- organizar documentação, versões e entregas.

### Conteúdo

1. instalação, configuração e identidade do autor;
2. `init`, `clone`, `status`, `add`, `commit`, `log` e `diff`;
3. branches, merge, rebase e resolução de conflitos;
4. remotos, `fetch`, `pull` e `push`;
5. issues, pull requests, revisão e proteção da branch principal;
6. README, licenças, tags, releases e boas práticas de segurança.

### Projeto do workshop

Pela abordagem **ApP**, os participantes criam um pequeno projeto, registram
sua evolução em commits claros, implementam uma melhoria em branch separada e
concluem o fluxo com pull request, revisão e release.

### Público e requisitos

Indicado para estudantes, desenvolvedores e equipes que desejam adotar um
processo de versionamento confiável. É necessário um computador com acesso ao
terminal e uma conta no GitHub; experiência prévia com Git não é obrigatória.

### Resultado esperado

Ao final, o participante terá um repositório público ou privado organizado e
será capaz de executar o fluxo cotidiano de desenvolvimento colaborativo.
